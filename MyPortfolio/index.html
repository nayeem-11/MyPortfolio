DEEP DIVE ARCHITECTURE

Behind the Build: PrintIt

PrintIt explores how a digital platform can simplify the interaction between customers and printing services.

The Problem

Traditional printing workflows can involve manual document sharing and coordination between customers and print shops.

PrintIt explores a digital approach to organizing this workflow into a predictable, structured system.

The Approach

My primary focus was building a functional prototype integrating frontend interaction with cloud services:

  • Developed the web application interface with responsive layout.
  • Worked with Supabase for database schemas and backend functionality.
  • Deployed the application using Vercel for continuous hosting.
  • Used Antigravity as part of the development and engineering workflow.

Application Development: Structuring UI components, validating form entries, and managing interactive frontend states.
Database Integration & Management: Connecting application endpoints with Supabase table schemas and managing records.
Deployment & Hosting: Configuring production deployments on Vercel and managing environment builds.
